# Relatório de QA — Sales Intelligence

Data: 29/09/2026  
Perfil: QA sênior — usuário cliente (`company_admin`)  
Ambiente: local (`127.0.0.1:3000`), navegador Edge headless, viewport desktop e mobile

## Resultado

**Aprovado após correções.**

O teste ponta a ponta `npm run test:customer-qa` passou cobrindo:

- login e redirecionamento para o dashboard;
- menu lateral, indicação de localização e estado ativo persistente;
- central de ajuda com imagens;
- onboarding com menu lateral disponível;
- criação e edição do lead;
- análise assistida sem ação externa;
- geração e aprovação de rascunho sem envio automático;
- criação de tarefa de follow-up;
- prévia, detecção de duplicado e confirmação de importação CSV;
- layout mobile sem overflow horizontal;
- ausência de erros JavaScript e de chamadas externas inesperadas.

## Defeitos encontrados e corrigidos

1. Tarefas: o campo `datetime-local` era enviado sem ISO/fuso e a API rejeitava a criação. O formulário compartilhado agora converte o valor para ISO antes do envio.
2. Importação CSV: linhas duplicadas dentro do mesmo arquivo não eram identificadas. A validação agora compara as linhas com os leads existentes e com as linhas anteriores do próprio arquivo.

O cenário é local e não substitui testes de infraestrutura pública, TLS/WAF, recuperação de senha, confirmação de e-mail ou MFA, que permanecem fora do escopo desta execução.
